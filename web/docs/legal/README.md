# 이음수첩 법률 문서 초안

이음수첩의 현재 예시 체험과 향후 정식 운영을 위한 약관, 개인정보 처리방침 및 고지 문안입니다. 법률 MCP로 기준일의 조문을 확인하고, korean-humanizer 지침에 따라 법적 조건과 격식을 유지하며 한국어 문장을 다듬었습니다.

작성 기준일은 2026년 11월 21일입니다. 이 폴더의 정식 서비스용 초안과 별도로, 현재 Next.js 예시 체험에 맞춘 문서를 앱에 연결했습니다. 공개 배포는 아직 하지 않았으며 기존 공모전 기획서와 HTML 시연판도 수정하지 않았습니다.

## Next.js 앱에 연결한 문서

| 경로 | 내용 |
| --- | --- |
| `/terms` | 현재 무료 예시 체험에 적용하는 이용약관 |
| `/privacy` | 답변의 화면 메모리 처리, 테마 저장, 문의 및 권리 행사 |
| `/copyright` | 서비스 자료와 이용자 내용의 권리 및 침해 신고 |
| `/ai-notice` | 실제 AI 분석이 없는 현재 예시 체험의 범위 |
| `/licenses` | 외부 구성요소와 열람 가능한 라이선스 원문 |

홈 하단에서 모든 문서로 이동할 수 있습니다. 앱 게시본의 원문은 `web/lib/legal-documents.ts`, 연락처와 수정일 및 링크는 `web/lib/legal-config.ts`에서 관리합니다. 공개 라이선스 원문은 `web/public/licenses/`에 있습니다. 앱 게시본에 이 폴더의 정식 서비스용 초안을 그대로 노출하지 않습니다.

현재 공개 호스팅이 선정되지 않았으므로 `/privacy`에도 그 사실을 명시했습니다. 실제 배포 사업자가 정해지면 접속기록, 처리 위치와 기간 및 문의 메일의 실제 계약과 국외 처리 조건을 확인해 해당 항목을 구체화한 뒤 공개합니다. 실제 건강정보와 외부 AI 기능을 도입하기 전에는 아래 정식 서비스용 초안의 운영 조건도 확정해야 합니다.

앱 반영 검증에서는 린트 오류 0건(기존 UI 경고 5건), TypeScript 검사 및 프로덕션 빌드를 확인했습니다. 5개 경로를 모바일 402×874와 데스크톱 1280×900의 라이트 및 다크 모드에서 확인하여 가로 넘침, 끊긴 목차 링크 및 브라우저 실행 오류가 없음을 확인했습니다. 본문 표본의 명도 대비는 최소 7.81:1이며, 홈 하단 링크와 본문 바로가기 및 라이선스 원문 25개에 대한 접근도 확인했습니다.

## 문서에서 정한 핵심 원칙

당사자의 동의와 보호자의 개별 승인은 서로 다른 절차입니다. 성인 당사자의 의사를 우선하고 대리 동의는 실제 대리권을 확인합니다. 건강정보 저장, 외부 AI 처리, 국외 이전 및 QR 제공은 필요한 동의를 구분해 받습니다.

1단계 QR은 코드를 가진 불특정 사람이 볼 수 있다는 점을 알리고 선택 동의를 받는 설계안입니다. 10분 무응답으로 2단계를 자동 공개하지 않습니다. 법정 보안 접속기록의 보관은 이용자용 열람 이력과 구별합니다.

현재 코드는 예시 체험이므로 서버 저장, 암호화와 AI 보관 조건이 이미 구현되었다고 표시하지 않습니다. 한국어 윤문에서도 수치, 법적 요건과 선택권을 줄이지 않았습니다.

## 게시 전에 확정할 항목

1. 실제 게시일 및 시행일, 정식 서비스의 요금 여부
2. 호스팅, 이메일 처리, 인증, 문자, DB 및 파일 저장의 실제 처리 주체와 조건
3. AI 수탁자의 계약 법인과 연락처, 처리 국가, 보관기간, 재수탁자 및 실제 무보존 적용 여부
4. 백업 최종 파기, 인증 이벤트, 미수락 초대 및 동의 증빙의 보관기간
5. QR 1단계 공개의 항목, 수신자 범위와 적법한 별도 동의 방식
6. 전 항목 비공개 선택, 철회, 대리권 확인 및 직접 입력 대안의 실제 구현
7. COMPASS 자료의 이용 권한, 누락된 affectUI 고지와 팀 제작물의 권리 귀속

`[게시 전 입력]`, `[선정 전]` 등이 남아 있는 문서는 확정된 현행 정책처럼 게시하지 않습니다. 구체적인 조문 근거와 기획서의 수정 필요 지점은 [운영 확인 사항](legal-review.md)에 모았습니다.
