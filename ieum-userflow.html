유저 플로우

서비스이음수첩 · 돌봄 노하우를 잇는 AI 돌봄 인수인계서
흐름평소에 말과 사진으로 쌓은 인수인계서가 보호자가 갑자기 쓰러진 순간 휴대폰 QR로 이어집니다. 1단계(알레르기·약)는 누구나 보지만 열자마자 보호자에게 알림이 가고, 2단계는 보호자나 대리 보호자가 10분 안에 승인해야 열립니다. ③이 핵심 상황입니다.
레인보호자·대리 보호자 / AI / 긴급 돌봄자 / 당사자 / 시스템
표시
시연에서 실제 동작 시연에서 모의 처리 (문자 인증·승인·10분 대기) 화면 목업 (시연 범위 밖) 갈림길 시작 위기 상황 단계 사이 이어짐
가로로 넘기면 ①~⑤를 모두 볼 수 있습니다.

단계별 흐름

① 가입·평소 기록문자 인증으로 가입(체험 모드는 모의, 이후 로그인은 전화번호·비밀번호) → 초기 설정(보호자·당사자 정보, 알레르기·위험행동) → 공개 범위(1단계는 알레르기·약만, 보호자 본인 정보는 기본 꺼짐) → 당사자 쉬운 말 동의 → 대리 보호자 초대(건너뛰기 가능, 수락·동의해야 성립, 2단계 허락 권한 위임) → 복약안내문 촬영 또는 음성 기록 → AI 정리·되묻기 → 보호자 확인 → 인수인계서 갱신(최근 저장일)
② 자리비움 시작 (미리 알 때)홈에서 자리비움 → 만료 링크 생성 → 돌봄자에게 전달 → 당사자 카드 준비
③ 보호자가 갑자기 쓰러졌을 때보호자 휴대폰의 QR 스캔 → QR 1단계(알레르기·복용 약·주의 약 종류) → 로그·IP 제공 동의 → 1단계 기본 열람 확인, 동시에 보호자·대리 보호자에게 열람 알림(시각·기기·IP, 위치 없음) → 2단계 열람 요청(열람자 유형·사유) → 보호자·대리 보호자에게 승인 요청 → 10분 안에 승인하면 2단계 / 거절하거나 10분이 지나면 요청 만료, 1단계만
④ 돌봄 중2단계 상세(복약·식사·일과·연락처) → 안심 카드·일과표 보여 주기 → 식사·복약 체크와 한 줄 기록
⑤ 복귀·이음복귀 → 돌봄 기록·열람 기록 확인 → 인수인계서 반영 → 링크 만료 → 평소 상태
어느 단계에서든보호자·대리 보호자는 알림에서 열람을 막고 QR을 새로 발급할 수 있습니다.
